# Code of conduct

This project is a place for people to work on jewellery software together. To keep it that way:

* **Be respectful.** Disagree with ideas, not with people. No harassment, insults, discrimination or
  personal attacks, in issues, pull requests, discussions or anywhere else the project is represented.
* **Assume good faith**, and say so when you are not sure what someone meant.
* **Be welcoming** to newcomers, and to people whose first language is not English or Turkish.
* **Respect privacy.** Do not post other people's files, customer details or credentials.
* **Keep it on topic** and constructive.

Maintainers may edit, hide or remove comments, close issues and pull requests, and block accounts that
break these rules. To report a problem, contact the maintainer through a private GitHub security
advisory or the contact details on their profile.

This code is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org).
